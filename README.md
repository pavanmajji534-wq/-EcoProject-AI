## 📖 Overview

**EcoProject AI** is an intelligent web application designed for students, researchers, and community innovators to bridge the gap between environmental challenges and actionable technical solutions. 

Unlike traditional platforms that rely on predefined static templates, EcoProject AI functions as an active problem analyst:
1. **Strict Environmental Classification:** Automatically verifies whether an input addresses a genuine sustainability challenge and rejects non-environmental topics with targeted clarification feedback.
2. **Root Cause & Constraint Extraction:** Deconstructs specific operational, behavioral, and physical bottlenecks (e.g., thermal perishability, concealed pipe leaks, gate traffic bottlenecks).
3. **Logically Connected Solutions:** Directly maps every engineering countermeasure to an identified cause, respecting user-selected difficulty levels and deployment environments.
4. **Export-Ready Proposals:** Generates comprehensive academic and hackathon project proposals exportable to Markdown and PDF.

---

## ✨ Key Features

- 🔬 **Dynamic Semantic Analysis:** Zero generic boilerplate. Every problem statement, cause, impact, and solution is uniquely synthesized based on actual user input.
- 🛡️ **Relevance & Specificity Gate:** Prevents non-environmental queries (crypto, gaming, homework, etc.) from generating arbitrary outputs.
- 🎯 **Logical Cause-to-Solution Chain:** Guarantees that the proposed technical architecture directly solves the specific causes and constraints described.
- ⚙️ **6-Point Architecture Breakdown:**
  - *What is Monitored?*
  - *Who Uses the System?*
  - *What Data is Collected?*
  - *How Technology is Applied?*
  - *What Action is Taken?*
  - *How Environmental Impact is Reduced?*
- 🛠️ **Adaptive Tech Stack Sizing:** Automatically tailors hardware (Arduino, ESP32, Jetson), software frameworks (Flask, FastAPI, PyTorch), and telemetry (Wi-Fi, MQTT, LoRaWAN) based on project complexity (**Beginner**, **Intermediate**, or **Advanced**).
- 🧠 **Dual-Engine Architecture:**
  - **Built-in Semantic Analyst:** Instant, high-specificity contextual analysis running entirely in the browser (100% offline, zero setup).
  - **Live Google Gemini Engine:** Direct integration with `gemini-3.6-flash` for advanced generative reasoning.
- 📥 **One-Click Export:** Instant download as Markdown (`.md`), copy-to-clipboard, or print/save as PDF.

## 🚀 Getting Started

### 1. Run Locally
No build steps or dependencies required!
1. Clone or download this repository:
   ```bash
   git clone https://github.com/<your-username>/ecoproject-ai.git
   ```
2. Open `index.html` in any modern web browser (Chrome, Edge, Firefox, Safari).

### 2. Live Deployment (GitHub Pages)
1. Fork or push this repository to GitHub.
2. Go to **Settings** $\rightarrow$ **Pages**.
3. Set the source branch to **`main`** and folder to **`/ (root)`**.
4. Click **Save** — your site will be live in 1–2 minutes!
