3. HOW TO UPLOAD FILES TO GITHUB (STEP-BY-STEP)
--------------------------------------------------------------------------------
1. Open your repository on https://github.com
2. Click the button near the top right of the file list:
      [ Add file ▾ ]  -->  select "Upload files"
3. Drag and drop the following files into the upload box on GitHub:
      - index.html   (Your main website file)
      - README.md    (Your repository documentation)
4. Scroll to the bottom and click the green "Commit changes" button.


--------------------------------------------------------------------------------
4. HOW TO GET YOUR LIVE PUBLIC LINK (GITHUB PAGES)
--------------------------------------------------------------------------------
1. In your GitHub repository, click the "Settings" tab (gear icon at the top).
2. In the left sidebar, click on "Pages" (under Code and automation).
3. Under "Build and deployment":
      - Source: Deploy from a branch
      - Branch: Select "main" (or "master") and folder "/ (root)"
      - Click "Save".
4. Wait 1 to 2 minutes, then refresh the page.
5. Your live website URL will appear in a green banner:
      https://<your-username>.github.io/<your-repo-name>/
